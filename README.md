# Mini ATM V1 — Operaciones Iterativas y Validaciones

Proyecto de consola en C# desarrollado para el Laboratorio 3.10 (Semana 3, Día 2).

## Características implementadas
- Ciclo iterativo do-while controlado por la opción Salir (RN-09, RN-10).
- Menú de 4 opciones gestionado con switch (RF-02).
- Validaciones numéricas robustas con int.TryParse y decimal.TryParse (RN-11).
- Control estricto de fondos, montos positivos y estado de cuenta (RN-01 a RN-07).
- Persistencia de saldo en memoria entre operaciones consecutivas (RN-12).

## Casos de Prueba Superados
Cumple al 100% con los escenarios de prueba CP-01 al CP-12 del documento BRD-ATM-3.10.
